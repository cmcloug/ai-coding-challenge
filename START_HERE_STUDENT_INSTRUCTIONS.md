# Technical Challenge: Choose Your Track

**Time:** 90 minutes (about 60 of that is hands-on work)
**Format:** Individual
**Tools:** Use whatever you like, **including AI tools**. We want to see how you work with them.

---

## How this works

You will pick **one** of three tracks. Each is designed to take roughly 45 to 60
minutes for a solid core result, with stretch goals if you finish early. No track
is "easier" than the others. They test different skills.

| | Track 1: Fix and Extend | Track 2: Review AI Code | Track 3: Messy Data to Insight |
|---|---|---|---|
| **You get** | A small Python app with failing tests | A Python file written by an AI | A messy sales dataset |
| **You do** | Fix the bugs, then add two features | Review it like a pull request and fix the worst problems | Clean the data, find insights, make a recommendation |
| **Good fit if you like** | Debugging, reading code | Security, quality, critical thinking | Data, storytelling, ambiguity |
| **Folder** | `track1_fix_and_extend` | `track2_review_ai_code` | `track3_data_to_insight` |

You may switch tracks **once**, in the first 15 minutes, if you realize it is not a
fit. Tell the facilitator when you do.

---

## Ground rules

1. **AI is allowed and expected.** Use any assistant you want. Tell us which one.
2. **You are responsible for what you submit.** If AI gives you something wrong
   and you submit it, that is on you. Check its work.
3. **Keep a record of your AI use.** Save your prompts, or copy the conversation
   link. Rough notes are fine. This is not a trap. We want to understand your
   process.
4. **No installs needed.** Everything runs with a standard Python install and no
   extra packages. If you find yourself about to install something, ask first.
5. **Explaining beats finishing.** A partial solution you understand and can
   explain scores better than a complete one you cannot.

---

## What you submit

1. **Your work** (fixed code, review notes, or cleaned data and findings), committed to your private repo
2. **Your prompt log** as `PROMPT_LOG.md` (copy and paste, screenshots, or share links)
3. **The reflection** as `REFLECTION.md`, copied from `REFLECTION_TEMPLATE.md` (5 minutes, at the end)
4. **A 3-minute verbal walkthrough** with the facilitator

See `README.md` for how to create your private repo and share it with the facilitator.

## Quick tips

- **Read first.** Spend the first 5 minutes understanding what you were given
  before you open an AI tool.
- **Give AI context.** Specific prompts with the relevant code, error, or data
  sample get much better results than vague ones.
- **Verify.** Run the tests. Re-count the rows. Reproduce the bug. Do not take an
  answer on faith.
- **Ask when stuck.** Getting unstuck quickly is a skill too.

Good luck, and have fun with it.
